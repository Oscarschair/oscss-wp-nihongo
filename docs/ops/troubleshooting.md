# トラブルシューティングガイド (Troubleshooting Guide)

本ドキュメントでは、開発・運用中に発生しうる典型的な問題とその解決策をまとめます。

---

## 1. よくある問題と対処法

### Q1. CSSやJSの変更が反映されない
- **原因**: ブラウザまたはCDN / サーバーのキャッシュが残っている。
- **対処**:
  1. `functions.php` の `OSCSS_THEME_VERSION` の数値を更新する。
  2. ブラウザのスーパーリロード（`Ctrl + F5` または `Cmd + Shift + R`）を実行する。

### Q2. SP（スマホ）でハンバーガーメニューが開かない
- **原因**: `assets/js/main.js` が正しくエンキューされていない、または他プラグインのJSエラーで実行が中断している。
- **対処**:
  1. ブラウザのDevToolsコンソールでJSエラーが発生していないか確認。
  2. `footer.php` に `wp_footer()` が呼ばれているか確認。

### Q3. アイキャッチ画像が表示されない
- **原因**: 投稿にアイキャッチ画像が設定されていない、またはデフォルトプレースホルダーが見つからない。
- **対処**:
  - `functions/utility.php` の `oscss_get_thumbnail_url()` が正しく動作しているか確認。
  - `assets/images/placeholder.svg` が存在するか確認。

### Q4. 抜粋の文字数が反映されない
- **原因**: 他プラグイン（SEOプラグイン等）が `excerpt_length` フィルターを上書きしている。
- **対処**:
  - `functions/filter.php` のフィルターフック優先度（プライオリティ）を `999` 以上に設定。
