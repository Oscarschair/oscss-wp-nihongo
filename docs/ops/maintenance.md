# 保守・運用手順書 (Maintenance Guide)

本ドキュメントでは、テーマ運用時の日常保守・キャッシュクリア・アップデート手順を定めます。

---

## 1. キャッシュクリア運用 (Cache Purge)

CSSやJavaScript、PHPテンプレートを変更した後は、以下の手順でキャッシュを破棄します。

### 1.1 ブラウザキャッシュの強制更新
- `functions.php` 内の `OSCSS_THEME_VERSION` 定数をインクリメント（例: `1.0.0` &rarr; `1.0.1`）することで、エンキューされるアセットURLのクエリ文字列が更新され、全ユーザーへ最新アセットが配信されます。

### 1.2 サーバー側キャッシュ / OPcache のクリア
- サーバー上でキャッシュプラグイン（WP Super Cache / LiteSpeed Cache / W3 Total Cache等）を利用している場合は、管理画面またはWP-CLIから全キャッシュを消去します。
- OPcache有効環境では `opcache_reset()` を実行するか、Webサーバーを再起動します。

---

## 2. テーマのアップデート手順

1. **バックアップ取得**: `wp-content/themes/oscss-wp-nihongo` の現行ファイルを退避。
2. **ファイル配置 / Git Pull**: 新しいバージョンを作業ブランチからマージまたは配置。
3. **バージョン番号の確認**: `style.css` および `functions.php` のバージョンが一致していることを確認。
4. **表示検証**: PC（1280px+）およびSP（375px〜414px）で表示崩れがないか確認。
