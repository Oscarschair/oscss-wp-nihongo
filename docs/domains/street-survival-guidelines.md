# 「街角サバイバル」連載記事 構成規格 ＆ 持ち物（装備品）ルール仕様書

## 1. 概要と目的
「街角サバイバル（street-japanese）」は、日本のリアルな日常現場（コンビニ、駅、病院、居酒屋、銭湯など）に直面した外国人学習者・在住者が、RPGのダンジョン攻略感覚で楽しく実践的サバイバル術を学べる超人気連載企画です。

本仕様書は、読者の没入感と実用性を極限まで高めるため、**記事本文の構成フォーマット** および **「毎回持ち物（装備品）をダンジョンに合わせて変える」運用ルール** を定義します。

---

## 2. 街角サバイバル記事の標準構成（6大ステップ）

すべての街角サバイバル記事は、以下の統一された6部構成で執筆します：

```
【 街角サバイバル 標準記事構成ツリー 】
├── ① ダンジョン突入（プロローグ・異文化ショック）
├── ② 🎒 今回のダンジョン装備（持ち物リスト / インベントリ）★必須義務
├── ③ ダンジョン全体マップ（フロア進行フロー）
├── ④ 敵の波状攻撃（3大トラップ・現場の早口質問）
├── ⑤ 必勝サバイバルコマンド（神フレーズ ＆ 選択肢チャート）
└── ⑥ クエストクリア ＆ オスカーの冒険メモ（エピローグ）
```

### 詳細各ステップの役割

1. **① ダンジョン突入（プロローグ）**:
   - 香港・海外での日常（例：無言レジ、ドアノブ放置配達）と、日本でのギャップを描写。
   - オスカーが目の前でフリーズし、RPGのバトル画面に引きずり込まれる緊迫の瞬間。
2. **② 🎒 今回のダンジョン装備（持ち物リスト / インベントリ）★毎回固有設定**:
   - **そのダンジョンに挑む際に「必ず持っていくべきリアルな持ち物」をRPGの装備品として定義**。
   - **固定の「剣と盾」の使い回しを完全禁止**し、現場に直結した具体的アイテムを設定する。
3. **③ ダンジョン全体マップ（進行フロー）**:
   - 入店（受付）から退店（ゴール）までのフロア進行をわかりやすく箇条書きや図解で整理。
4. **④ 敵の波状攻撃（3大トラップ）**:
   - 店員やシステムから矢継ぎ早に浴びせられる質問や選択肢（「店内？お持ち帰り？」「温めますか？」「保険証は？」など）の構造を暴く。
5. **⑤ 必勝サバイバルコマンド（神フレーズ）**:
   - レトロRPGのコマンドウィンドウ風（`【 コマンド選択 】`）で、場面ごとの最適解フレーズを提示。
6. **⑥ クエストクリア ＆ オスカーの冒険メモ**:
   - ダンジョンを無事突破した達成感と、そのマナーや手続きがなぜ日本で発達したのかという文化的背景の解説。

## 5. 🎨 サムネイル画像との完全連動ルール

### 「剣と盾」固定の永久禁止
1. **中世の剣と盾は完全廃止**:
   - 街角サバイバルにおいて、中世騎士風の「鉄の剣」や「紋章の盾」をオスカーに持たせることを永久に禁止する。
2. **リアル持ち物（装備品）の武器化・防具化**:
   - オスカーの両手には、上記マスターマトリクスで定義された「その現場固有の持ち物」を武器・防具として構えさせる。
   - 口にくわえるアイテム（体温計、きっぷ、ペンキャップ、ストロー、整理券など）を活用し、コミカルさと現場感を極限まで高める。
3. **RPGコマンド枠の維持**:
   - 下部の「▶たたかう / どうぐ / にげる」青色コマンドウィンドウと、上部黄色ピルタグはそのまま維持し、RPGの様式美を演出する。

## 6. 🛡️ 今後の重複防止プロトコル（Duplication Prevention Protocol）

今後、街角サバイバル記事およびサムネイル・挿入画を新規作成する際は、以下のチェックを必須義務とする：

- [ ] **1. 本マスターマトリクス（第4章）の照合義務**:
  - 新規テーマを決定した際、まず本表を開き、過去に使用したアイテム（特に「口にくわえるもの」「右手」「左手」）と重複していないか確認する。
- [ ] **2. 現場固有のリアルアイテムの選定**:
  - そのシチュエーションで日本在住者・旅行者が実際に手に持つリアルな道具・紙片・ガジェットから、最も象徴的な3大アイテム（メイン・サブ・お助け）を選定する。
- [ ] **3. 台帳への追記**:
  - 新しいダンジョンを公開した際は、本ドキュメントの表に新たな装備組み合わせを追記・永続記録し、次回の制作時に参照できるようにする。
