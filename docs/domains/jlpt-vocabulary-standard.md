# JLPT語彙標準 ＆ 記事難易度判定ガイドライン

## 1. 概要と目的
本ドキュメントは、『オスカーの日本語学習帳』における記事ごとの **日本語能力試験（JLPT）目安レベル判定（N5〜N1）** および使用語彙の品質基準を定義する生きたドメイン仕様書（Single Source of Truth）です。

読者が自身の日本語レベルに合わせて安心して記事を選び、快適に学習を進められるよう、感覚的な主観判定を排除し、公式語彙データに基づいた客観的な語彙解析アルゴリズムによって判定します。

| レベル | 対象読者のイメージ | 当サイトでの主な記事カテゴリ・内容 |
| :--- | :--- | :--- |

## 4. 判定アルゴリズム（不変条件）

言語教育における語彙カバレッジ理論（テキストの85〜90%の語彙を知っていれば文脈から自力読解が可能）に基づき、以下のルールで判定します：

1. **語彙カバレッジの算出**:
   - 記事本文のプレーンテキストを走査し、N5〜N1語彙のマッチング数を集計。
   - `累積N4カバー率 = (N5出現数 + N4出現数) / 総マッチ語数`
   - `累積N3カバー率 = (N5出現数 + N4出現数 + N3出現数) / 総マッチ語数`
   - `上級語彙比率 = (N2出現数 + N1出現数) / 総マッチ語数`
2. **判定基準**:
   - **N2**: 上級語彙比率 $\ge 17\%$、またはN2個別語彙 $\ge 35$ 語、または制度・契約・ビジネスマナー等の高度なテーマ。
   - **N3〜N2**: 上級語彙比率 $\ge 14\%$ かつ N2個別語彙 $\ge 25$ 語（クリニック、役所、専門手続き等）。
   - **N4〜N3**: 累積N4カバー率 $\ge 52\%$（基本語彙中心の日常表現）。
   - **N3**: 累積N3カバー率が $85\%$ 以上に達し、中級語彙が主体の標準記事。

## 5. 運用ツール（CLI実行手順）

新規記事の作成時や推敲時、以下のコマンドを実行することで、瞬時に語彙分布と推奨JLPTレベルを確認できます：

```bash
python scripts/core/check_post_jlpt.py content/posts/YYYY-MM-DD-your-article.md
```
