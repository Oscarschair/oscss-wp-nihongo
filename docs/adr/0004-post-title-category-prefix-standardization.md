# ADR 0004: 投稿タイトルのカテゴリー名プレフィックス必須化および表記統一

## ステータス
承認済み / 適用完了 (Accepted & Applied) - 2026-09-23

## 背景・コンテキスト
WordPress管理画面一覧や読者の記事一覧において、一部の投稿で「カテゴリー名プレフィックス（例: `街角サバイバル：`、`ことばのあや：`等）」が付いていない記事が混在していた。
また、「くらべて納得！」と「くらべてみました」など、WordPress正式カテゴリーターム名とタイトル・メタデータの表記揺れが発生していた。

これにより以下の課題が生じていた：
1. 読者が記事タイトル単体を見たときに、どの連載企画（文法対比、街角サバイバル、慣用句解説、文化比較）なのか直感的に判別できない。
2. WordPress管理画面やカテゴリー別絞り込みにおいて、タイトルの一貫性が損なわれ管理コストが増加する。
3. ユーザー（サイトオーナー）のブランド認識と乖離が生じる。

## 決定事項
すべての記事タイトルに対し、以下の命名ルールを不可侵の基準として統一・強制する：

1. **フォーマット**:
   `{正式カテゴリー名}：{タイトル本文}`
   - 区切り文字は必ず全角コロン（`：`）とする。
   - プレフィックス自体にはルビタグを付けずプレーンテキストとする。
2. **正式プレフィックス（4分類完全固定）**:
   - `くらべてみました：`（旧「くらべて納得！」等は完全廃止）
   - `街角サバイバル：`
   - `ことばのあや：`
   - `カルチャーショック：`
3. **自動セーフティガードの実装**:
   - `scripts/core/repair_all_posts_gutenberg.py` にプレフィックス自動判定・補完ガードを内蔵し、手動入力漏れがあっても同期時に自動補完される仕組みを導入。
   - `scripts/audit/audit_title_prefixes.py` を整備し、全記事のプレフィックス充足率100%を維持。

## 影響と効果
- **メリット**:
  - 全記事のタイトルフォーマットが100%統一され、ブランド視認性・連載としての統一感が劇的に向上した。
  - 管理画面一覧でもルビ除去JS（プランA）と連動し、すっきりと揃ったタイトル一覧が実現。
  - 新規記事執筆時・同期時にも自動ガードによりルール違反が未然に防止される。
- **留意点**:
  - タイトル変更による既存URLスラッグへの影響はなく、URL（パーマリンク）は保持される。
