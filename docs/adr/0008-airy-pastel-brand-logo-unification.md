# 0008: サイト全体の淡彩パステル世界観に調和するブランドロゴ・光学補正ファビコン一括刷新

- **日付**: 2026-11-18
- **ステータス**: 承認済み (Accepted)
- **決定者**: 開発チーム / サイトオーナー

## コンテキスト (Context)
従来の「オスカーの日本語学習帳（`oscss-wp-nihongo`）」には以下のブランド表現上の課題が存在した：
1. **ヘッダーロゴマークの不在**: `header.php` がプレーンテキストのみで出力されており、サイトの象徴となるシンボルが存在しなかった。
2. **ファビコンの縮小視認性低下**: 旧 `favicon-512x512.png` は細線かつ丸顔と右パーツの境界が曖昧で、16×16px / 32×32px 縮小時に内窓が潰れやすかった。
3. **フッター・構造化データのトーン不整合**: `footer.php` や `functions/seo.php`（JSON-LD `Organization.logo`）でメインサイト（AIノート）向けのサイバー回路背景アイコン（`my-icon.png`）が流用されており、本サイトの淡い水彩・パステル調（ヒーロー背景 `#EEF2FF` → `#F5F3FF` → `#FFF1F2`、および手描きコミックエッセイ調のイラスト）と乖離していた。
4. **色彩・ウェイトの調和要件**: 一般的な企業ロゴのような高彩度原色ベタ塗りや極太黒文字を配置すると、本サイト特有の優しい淡彩パステル空間から重たく浮いてしまうことが視覚検証で判明した。

## 決定事項 (Decision)
1. **エアリー・パステルシンボル × 高視認ブラックタイポグラフィ2段ミニマルロゴ（案 1-B 視認性強化版）の採択**:
   - モチーフは「淡彩の見開き学習帳 × 対話の吹き出し × ベビー桜しおり」とし、塗り色をサイトFVと同系の極淡パステル（`#EBF0FF` / `#F4F0FF` / `#FCE4F0`）、輪郭線をやわらかなくすみスレート藍（`#6872A0`, 線幅 `4.5`、しおり交差部の裏線カット処理済）で設計する。
   - ワードマークはグローバルナビゲーション（`#1E293B`）に対する主役としての視覚的階層（Visual Hierarchy）と WCAG 2.2 AAA コントラストを保証するため、主文字をディープスレートブラック（`#0F172A`, `Noto Sans JP wght=680`, コントラスト比 `17.85:1`）、欧文サブタイトルをスレートブラック（`#1E293B`, `Noto Sans Bold`, コントラスト比 `14.63:1`）の2段ミニマル構成とし、全グリフを純粋ベクター `<path>` へアウトライン化して外部フォント依存を排除する（`assets/images/logo-lockup.svg` / `logo-lockup-dark.svg` / `logo-symbol.svg`）。
2. **Optical Sizing（光学サイズ補正）ファビコンの導入**:
   - ヘッダー表示では繊細な細線（`3.9`）を維持しつつ、`32×32px` / `16×16px` / `favicon.ico` 用の極小アイコンでは縮小時の線消失を防ぐため、同一パステルトーンのまま線幅（`7.0`）と外枠コントラストを光学補正した専用マスターから生成する。
3. **ヘッダー・フッター・JSON-LD の一括統一**:
   - `header.php` に `logo-lockup.svg`、`footer.php` にダーク背景最適化版 `logo-lockup-dark.svg` を配置する。
   - `functions/seo.php` の JSON-LD において、`Organization.logo` には `logo-organization.png`（512×512px）、著者 `Person.image` には本サイト用の水彩トーンアイコン `x-profile-icon.png` を割り当て、サイバー回路背景アイコンの混在を解消する。

## 影響・結果 (Consequences)
### メリット (Positive)
- ファーストビューの淡彩パステルグラデーションおよび主人公オスカーのイラストと完全に調和しつつ、メディアとしての記憶定着性と信頼感が向上する。
- 純粋ベクター `<path>` アウトライン済みSVGのため、OS・ブラウザを問わずフォント崩れゼロかつ超軽量に表示される。
- Optical Sizing により、ヘッダーでの繊細さとブラウザタブ（16px）での明瞭な識別性を両立できる。

### デメリット・トレードオフ (Negative / Trade-offs)
- サイト名文字列をSVG `<path>` としてアウトライン化しているため、将来サイト名称自体を変更する際はSVGの再エクスポートが必要となる（アクセシビリティおよびSEO上のサイト名は `alt` 属性・`aria-label`・JSON-LD で担保する）。
