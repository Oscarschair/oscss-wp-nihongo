# 0001: モジュラーPHPアーキテクチャおよび日本語最適化テーマ設計の採用

- **日付**: 2026-09-04
- **ステータス**: 承認済み (Accepted)
- **決定者**: 開発チーム

## コンテキスト (Context)
WordPressテーマ開発において、単一の `functions.php` にすべてのフックやカスタムロジックを記述する従来のアプローチは、コードの肥大化・可読性の低下・保守困難を招く要因となっていました。
また、日本語サイト特有の文字詰め・行間・視認性アクセシビリティ（WCAG準拠）や、マルチデバイスでの表示崩れに対応した強固なCSS設計が必要でした。

## 決定事項 (Decision)
1. **PHPモジュラーアーキテクチャの採用**:
   - `functions.php` はローダーに限定し、`functions/` 配下に `action.php`, `filter.php`, `shortcode.php`, `utility.php` を配置して役割を厳格に分離する。
2. **8pt Gridシステム ＆ CSS Tokens**:
   - 余白・フォントサイズ・配色を `assets/css/tokens.css` で一元管理し、BEM命名規則に則ったCSSコンポーネント設計を行う。
3. **日本語組版に特化したタイポグラフィ**:
   - 最適化されたシステムフォントスタック、`line-height: 1.75`、適切な文字間隔と見出しの折り返しルールを採用する。

## 影響・結果 (Consequences)
### メリット (Positive)
- コードの見通しが良くなり、フックやヘルパー関数の追加・保守が容易になる。
- デザインシステムが一貫し、デバイス間でのレイアウト破綻を防止できる。
- 日本語テキストの可読性が格段に向上する。

### デメリット・トレードオフ (Negative / Trade-offs)
- ファイル数が増えるため、初期セットアップ時にテンプレート階層とモジュールローダーの理解が必要。
