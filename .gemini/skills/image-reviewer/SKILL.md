# 🎨 投稿サムネイル画像レビュー専門エージェント (Image Reviewer)

本スキルは、**「オスカーの日本語学習帳」**（https://nihongo.oscarchair.jp/）において、新記事のサムネイル画像生成・記事投稿時に、**各連載カテゴリーのデザイン形式の維持**と**主人公（オスカー）の登場・ビジュアル一貫性**を100%保証するための専門エージェントガイドラインです。

---

## 1. 🪝 発動トリガー ＆ ライフサイクルフック (Lifecycle Hooks)

本エージェントは以下の契機で自動発動（HOOK）または手動で実行されます：

| フック種別 | 発動タイミング | 実行内容 |
| :--- | :--- | :--- |
| **`post_image_generation`** | **`generate_image` でサムネイル画像を生成した直後** | 生成画像が主人公原型・カテゴリー形式を満たしているか即時バリデーション |
| **`pre_post_publish`** | **WordPressへ記事を投稿・公開する直前** | アイキャッチ画像が記事テーマ・連載カテゴリーと一致しているか最終品質チェック |
| **`post_file_save`** | **`content/posts/*.md` 保存時** | 記事Markdownに紐づくサムネイル画像が存在し、規格に適合しているか確認 |
| **手動指示** | ユーザーからの指示時 | 「サムネイルをレビューして」「画像チェック」「主人公が出ているか確認」等 |

## 3. 📐 カテゴリー別デザイン形式（系統分類ルール）

各連載カテゴリーのテーマに合わせ、以下の構図・カラー・必須要素を厳密に遵守して画像を生成・検証します。

```
連載カテゴリー別サムネイル規格
├── 🔍 くらべてみました (kurabete)
│   ├── 構図: 左右分割のVS対比構図（2つの概念・言葉・文化の比較）
│   ├── 主人公: 中央で両方の違いを真剣＆ユーモラスに考察・比較するポーズ（メモを取る、顎に手を当てる等）
│   ├── パネル: 左側にコーラルオレンジカード（対象A）、右側にライトブルーカード（対象B）
│   ├── 要素: 中央にポップな「VS」ロゴ、両カード内に大きな縦書きテキストと関連アイコン
│   └── 配色: 和モダン・パステルベージュ（青海波・幾何学パターン）
├── 🗣️ ことばのあや (kotoba-no-aya)
│   ├── 構図: 会話・コミュニケーション・気づきを象徴する構図
│   ├── 主人公: 左側にオスカー、右手で右側のカードを指し示す解説ポーズ
│   ├── 要素: 右側にラベンダー色のカード、吹き出し、電球（ひらめき）、ハート・握手・疑問符アイコン
│   └── 配色: 優しいパステルラベンダー（#F0E7F5）、ミントグリーン、ソフトピンク
└── 🌏 カルチャーショック (culture-shock)
    ├── 構図: 日本と海外（香港/中華圏/欧米）の日常・習慣・食文化のギャップ
    ├── 主人公: 驚きや発見のリアクション（指差し、キョロキョロ、目を丸くする等）
    ├── 要素: 対比となる具体的なアイテム（例: 氷水vs温かい急須、電車で寝る人々、おにぎりvsチャーハン）
    └── 配色: パステルオレンジ、スカイブルー、ライトイエローの明るいコントラスト
```

## 4. 🖼️ サムネイル共通フォーマット規格

- **アスペクト比**: **16:9**（横長、1920×1080 / 1280×720 相当）
- **タイポグラフィ**: 太字でポップな日本語見出しテキストを画面内に明瞭に配置（文字化け・意味不明な擬似文字列は完全排除）
- **アートスタイル**: クリーンで親しみやすいアニメ・ベクターイラスト調、滑らかなパステルグラデーション
- **保存形式**: JPG（WebP変換対応）、ファイル名は `thumb-post-{id}.jpg` または `thumb-{category}-{slug}.jpg`

## 5. ✅ サムネイル画像レビュー チェックリスト (Quality Gate)

サムネイル生成直後（`post_image_generation`）およびWordPress公開前（`pre_post_publish`）に以下をすべて検証（Pass / Fail）します：

- [ ] **1. 主人公・モデル原型の確認**: 公式モデル原型（`hero-oscar-v2.png`）と照合し、オスカー（茶髪マッシュ・丸メガネ・水色スウェット）が正確に登場しているか？
- [ ] **2. 腕・手チェック**: 腕が左右2本のみであり、指や体の奇形・不自然さがないか？
- [ ] **3. 表情・ポーズ**: 記事のシチュエーションに応じた自然なリアクション・考察・ポーズになっているか？
- [ ] **4. カテゴリー形式の合致**:
  - `くらべてみました`: 左右VS対比構図（左：オレンジ「対象A」、右：ブルー「対象B」、中央：VSロゴ、中央：オスカー）になっているか？
  - `ことばのあや`: 左にオスカー、右にラベンダーカードと会話吹き出し・ひらめき要素があるか？
  - `カルチャーショック`: 文化比較アイテムと驚き・発見リアクションが描かれているか？
- [ ] **5. UIバッジ干渉回避**: サムネイル左上（約110×30px）のカテゴリーバッジ領域に重要な文字やキャラクターの顔が被っていないか？
- [ ] **6. タイトル文字の可読性**: 日本語テキストに誤字やAI特有の文字化けがなく、明瞭に読めるか？
- [ ] **7. アスペクト比と解像度**: 16:9比率で、WordPressアイキャッチとして鮮明に表示されるか？
