# 🎨 投稿画像（サムネイル ＆ 本文挿入画）レビュー専門エージェント (Image Reviewer)

本スキルは、**「オスカーの日本語学習帳」**（https://nihongo.oscarchair.jp/）において、新記事のサムネイル画像および本文挿入画の生成・レビュー時に、**正本モデル原型（hero-oscar.png）の厳格な画風・等身統一**、**カテゴリー別デザイン形式の維持**、および**常識的・文化的シチュエーションの整合性**を100%保証するための専門エージェントガイドラインです。

---

## 1. 🪝 発動トリガー ＆ ライフサイクルフック (Lifecycle Hooks)

本エージェントは以下の契機で自動発動（HOOK）または手動で実行されます：

| フック種別 | 発動タイミング | 実行内容 |
| :--- | :--- | :--- |
| **`post_image_generation`** | **`generate_image` で画像を生成した直後** | 生成画像が主人公原型・頭身（3.5〜4等身）・画風を満たしているか即時バリデーション |
| **`pre_post_publish`** | **WordPressへ記事を投稿・公開する直前** | アイキャッチ画像および本文挿入画が記事テーマと一致しているか最終品質チェック |
| **`post_file_save`** | **`content/posts/*.md` 保存時** | 記事Markdownに紐づく画像が存在し、規格に適合しているか確認 |
| **手動指示** | ユーザーからの指示時 | 「サムネイルをレビューして」「挿入画の画風チェック」「主人公の等身確認」等 |

## 2. 🚨【最重要・必須義務】サムネイル生成・レビュー時の事前確認フロー

**サムネイル画像を生成する前、およびレビューを実施する前には、必ず以下の4ステップを実行すること。推測や記憶に頼った生成・レビューは一切禁止とする。**

```
【必須確認ステップ】
1. 記事のカテゴリーを特定する（カルチャーショック / 街角サバイバル / ことばのあや / くらべてみました）
       │
       ▼
2. 第4章「4大カテゴリー別サムネイル完全統一規格」を必ず開き、当該カテゴリーの必須要素・正本マスター画像を確認する
       │
       ▼
3. 画像生成時（generate_image）は、正本マスター画像（hero-oscar.png および 該当カテゴリー正本サムネイル）を必ず ImagePaths に指定して生成する
       │
       ▼
4. 生成後のレビュー時、第4章の全構成要素（パネル・ピルタグ・吹き出し・コマンドウィンドウ・対比カード・VSロゴ等）が100%揃っているかを厳密照合する
```

### 🎨 `hero-oscar.jpg` をベースとしたオスカーの詳細描画仕様（マスター定義）

正本 `hero-oscar.jpg` に描かれているオスカーの各パーツ・造形・描画タッチは、以下の特徴で厳密に固定されています。生成時およびレビュー時は本仕様との完全合致を必須条件とします。

#### ① 顔の輪郭・フェイスライン（スリムな顎 ＆ 爽やかな青年）
- **輪郭形状**: 頬から顎先にかけて滑らかに絞られた、すっきりとした**逆卵型〜自然なVライン（Slender youth jawline）**。
- **顎先（あご）**: 尖りすぎず適度な丸みを帯びつつも、きゅっと引き締まった細身の顎ライン。
- **【厳格禁止】丸顔・幼児顔（Chubby / Baby Face）の完全排除**:
  - 頬がふっくら膨らんだ下膨れの丸顔、赤ん坊や幼児のような球体フェイス、ちびキャラ特有のぷっくりした輪郭は**一切禁止**。20代前半の爽やかで知的な青年の骨格を維持すること。
- **肌色・血色**: 明るく透明感のあるナチュラルベージュ。頬骨付近にほんのり淡いピーチピンクの水彩ぼかし（健康的な血色）。

#### ② 目・眉・表情（親しみやすさと知性）
- **目（形状・大きさ）**: 大きすぎず小さすぎない、**自然なアーモンド形の親しみやすい瞳**。少女漫画や幼女アニメのような極端な巨大目、またはリアル劇画の細目は不可。
- **瞳（カラー・光彩）**: 温かみのある深みのあるダークブラウン（焦げ茶）。黒目の中に控えめでクリアな白いハイライトが1〜2点入り、生き生きとした表情。
- **眼鏡（トレードマーク）**:
  - **形状**: 完全な正円に近い**細フレームのラウンド型（丸メガネ）**。
  - **フレーム色**: 濃いダークブラウンまたはチャコールブラック。
  - **レンズ表現**: レンズ越しに瞳が濁らずクリアに見える描画。レンズ上部にさりげない斜めの光の反射（白ハイライト）が入る。
  - **位置**: 鼻筋の上に自然に乗っており、両目の中心にきれいにフィットしていること。
- **眉**: 髪の隙間から覗く、適度な太さのダークブラウンの整った眉。驚き・困惑時のコミカルなハの字眉や、爽やかな笑顔のアーチ。
- **表情の幅**: 好奇心に満ちた爽やかな笑顔、またはコミカルに口を開けたリアクション（「えっ!?」「冷たい!!」などのO字の口、吹き出しや冷や汗マークとの連動）。

#### ③ 髪型・髪色（無造作なウェーブマッシュ）
- **スタイル**: ボリューム感のある**無造作なウェーブ・くせ毛のマッシュヘア（Messy fluffy wavy brown hair）**。
- **毛先・束感**: 毛先が柔らかく外ハネし、頭頂部やサイドに適度な空気感（エアリー感）と自然なランダムな束感がある。
- **前髪**: 眉やメガネのフレーム上部に軽くかかる自然なウェーブバング。パッツン前髪や直毛、派手なツーブロックは不可。
- **髪色**: 温かみのあるモカブラウン／チェスナットブラウン（栗茶色）。水彩風の柔らかな光の濃淡グラデーション。

#### ④ 体型・プロポーション（5頭身の青年体型）

## 3. 🖼️ 本文挿入画（In-Article Illustrations）固有の厳格ルール

記事本文内に配置する挿入画（`assets/images/posts/*.jpg`）は、以下のルールを厳格に遵守します：

1. **画風・色合いの統一**:
   - すべての挿入画は、`zenzen-daijoubu-reassurance.jpg` と同じ**「クリーンな現代アニメ調・くっきりした主線・澄んだパステルカラー」**で統一する（過度な水彩画風・にじみ絵は禁止）。
2. **サムネイルとの重複構図の絶対禁止**:
   - サムネイルと同じ場面・同じ構図の使い回しは厳禁。
   - 記事本文で語られている**具体的な別エピソード、別場面、葛藤・失敗・気づきの瞬間**を切り出して描写すること。
3. **文化的・常識的シチュエーション考証の徹底（ユーザーフィードバック反映）**:
   - **美容室のシャンプー台**:
     - 布（フェイスペーパー）は**「眼鏡の上から目元にしっかり被せる」**。
     - **半透明や透け透けはNG（不透明な清潔な白い布）**。
     - 過度な水彩にじみを廃し、クリーンなアニメ調で描く。
   - **駅改札ダンジョン**:
     - 改札機で扉が閉まり止められた際、**「後ろに通勤客や通行人が並んで待たせてしまい焦る構図」**にする（後ろの人に迷惑をかけて申し訳ない心理）。
   - **「すみません」のシチュエーション**:
     - 記事の核心・冒頭エピソードと合致させ、**「街中で落としたハンカチを拾ってもらい、思わず『わっ、すみません！！』と頭を下げるシーン」**など、直感的で共感を呼ぶシチュエーションを描く。
   - **自販機リサイクルボックス**:
     - 穴にカップやペットボトルを捨てようとして「普通のゴミは捨てられないの!?」と驚愕するシーン。
   - **カフェのテイクアウト**:
     - 「紙カップのホットコーヒー」を「手渡しで大丈夫ですか？」と直接受け取るシーン。
4. **日本語テキストの完全性 ＆ 可読性**:
   - 吹き出し内の日本語は**人間が100%スラスラ読める正しい日本語**であること。
   - 「普通通」などの文字化け、AI特有の崩れ文字・不自然な漢字は厳格に排除・校正すること。
   - **【厳格禁止】挿入画内の英語テキストの完全排除**: 吹き出しや思考アイコンに英語（"100% perfect", "slacking off"等）を混在させず、純粋な日本語のみで表現すること。
5. **電子機器・小物の現実的整理（PAD・端末は1台のみ）**:
   - カフェやオフィスの机の上にタブレット（PAD）やPCを描く場合、**「PADは1台のみ」**に絞ること。
   - 立てかけたPADと平置きのPADが重複するなど、不自然な画面の乱立を禁止し、手前にはノートやペンを自然に配置すること。
