# 🎨 投稿画像（サムネイル ＆ 本文挿入画）レビュー専門エージェント (Image Reviewer)

本スキルは、**「オスカーの日本語学習帳」**（https://nihongo.oscarchair.jp/）において、新記事のサムネイル画像および本文挿入画の生成・レビュー時に、**正本モデル原型（hero-oscar.png）の厳格な画風・等身統一**、**カテゴリー別デザイン形式の維持**、および**常識的・文化的シチュエーションの整合性**を100%保証するための専門エージェントガイドラインです。

---

## 1. 🪝 発動トリガー ＆ ライフサイクルフック (Lifecycle Hooks)

本エージェントは以下の契機で自動発動（HOOK）または手動で実行されます：

| フック種別 | 発動タイミング | 実行内容 |
| :--- | :--- | :--- |
| **`post_image_generation`** | **`generate_image` で画像を生成した直後** | 生成画像が主人公原型・頭身（3.5〜4等身）・画風を満たしているか即時バリデーション |
| **`pre_post_publish`** | **WordPressへ記事を投稿・公開する直前** | アイキャッチ画像および本文挿入画が記事テーマと一致しているか最終品質チェック |
| **`post_file_save`** | **`content/posts/*.md` 保存時** | 記事Markdownに紐づく画像が存在し、規格に適合しているか確認 |
| **手動指示** | ユーザーからの指示時 | 「サムネイルをレビューして」「挿入画の画風チェック」「主人公の等身確認」等 |

## 2. 👤 主人公「クルマ（オスカー）」モデル原型 ＆ 画風・等身の絶対基準 (Invariants)

すべての画像（サムネイル・本文挿入画）は、**以下の公式モデル原型画像を必ず事前に確認・参照（ImagePathsに指定）**し、キャラクター造形・頭身・タッチを完全に統一します。

### 📌 公式モデル原型（Reference Master）
- **正本パス**: [`assets/images/hero-oscar.png`](file:///c:/Users/user/git/oscss-wp-nihongo/assets/images/hero-oscar.png)

| 項目 | 規定内容（不変条件・厳格基準） | 禁止事項（NG例・アンチパターン） |
| :--- | :--- | :--- |
| **頭身・プロポーション** | **3.5 〜 4頭身**（丸顔・童顔、手足が丸くぽてっとしている絵本デフォルメ調） | **5〜7頭身のリアル青年アニメ調、劇画調、頭身が高すぎる大人体型** |
| **画風・タッチ** | **絵本・コミックエッセイ風の温かい手描き水彩タッチ、柔らかなブラウン系の主線** | デジタルパキパキ線画、硬質なCG調、過度なリアル背景やリアル陰影 |
| **髪型・髪色** | ふんわりとした無造作な**茶髪マッシュ・ウェーブヘア**（fluffy brown wavy hair） | 黒髪直毛、金髪、派手なツーブロック、別人の髪型 |
| **眼鏡** | **真ん丸の細縁黒メガネ**（round thin-rimmed black glasses） | メガネなし、四角いビジネス眼鏡、サングラス |
| **服装** | **くすみ水色（ダスティブルー）のスウェット／クルーネック**、キャンバストートバッグ斜めがけ | 奇抜な衣装、スーツ（ビジネス特化の例外場面を除く通常私服時） |
| **解剖学的正確性** | **腕と手は必ず「左右2本のみ」**、指の数は5本 | 腕が3本以上、指が6本以上または融合している奇形 |

## 3. 🖼️ 本文挿入画（In-Article Illustrations）固有の厳格ルール

記事本文内に配置する挿入画（`assets/images/posts/*.jpg`）は、以下のルールを厳格に遵守します：

1. **サムネイルとの重複構図の絶対禁止**:
   - サムネイルと同じ場面・同じ構図の使い回しは厳禁。
   - 記事本文で語られている**具体的な別エピソード、別場面、葛藤・失敗・気づきの瞬間**を切り出して描写すること。
   - 例: サムネが「ラーメン＋半チャーハン＋餃子」なら、挿入画は「焼きそばパンの炭水化物×炭水化物」や「お好み焼き定食の驚き」を描く。
2. **常識的・文化的シチュエーション考証の徹底**:
   - **美容室のシャンプー**: 目元に置く布は「マスク」ではなく**「薄いフェイスガーゼ／フェイスペーパー」**。
   - **カフェのテイクアウト**: パンや袋物ではなく**「紙カップのホットコーヒー」**を「手渡しで大丈夫ですか？」と直接受け取るシーン。
   - **コンビニレジ**: サムネの総合質問攻めに対し、本文挿入画は「温かいお弁当と冷たいお茶を別々の袋に分けますか？」などの具体的なやり取り。
   - **駅改札**: Suica/ICカードのタッチでピンポーンと扉が閉まり焦るクルマ。
   - **日常・ビジネスの礼儀**: エレベーターの「お先にどうぞ」、ビジネスの「その節はどうも」など、等身を崩さずデフォルメ調のまま自然な会釈・気遣いを描く。
3. **日本語テキストの正確性**:
   - 吹き出し内の日本語は誤字脱字・AI崩れのない完全な日本語であること。

## 4. 📐 カテゴリー別サムネイルデザイン形式

サムネイル（16:9横長）は、以下の連載規格とカラーパレットに従います：

```
連載カテゴリー別サムネイル規格
├── 🏪 街角サバイバル (street-japanese)
│   ├── 構図: 日常のリアル現場でのRPGサバイバル対比。黄色（#FEF08A）のピルタグ＋大見出しカード
│   ├── 主人公（クルマ）: 勇者装備（水色スウェット＋剣/盾、困り眉）。毎回ポーズ変更義務！
│   └── 要素: 右側に笑顔の店員・NPC、下部に青いレトロRPGコマンドウィンドウ（日本語）
├── 🔍 くらべてみました (kurabete)
│   ├── 構図: 左右VS対比構図（左：オレンジ「対象A」、右：ブルー「対象B」、中央：VSロゴ）
│   └── 主人公: 中央で両者の違いをユーモラスに考察・比較するポーズ（毎回変化）
├── 🗣️ ことばのあや (kotoba-no-aya)
│   ├── 構図: 左側にクルマ、右側にパステルラベンダー（#F0E7F5）カードと会話吹き出し
│   └── 要素: ひらめき電球、ハート、疑問符アイコン
└── 🌏 カルチャーショック (culture-shock)
    ├── 構図: 日本と海外の日常・食文化・習慣のギャップ
    └── 主人公: 目を丸くした驚き・発見のリアクション（毎回新鮮なポーズ）
```

## 5. ✅ 画像レビュー チェックリスト (Quality Gate)

画像生成時および公開前に以下をすべて検証（Pass / Fail）します：

- [ ] **1. プロポーション（3.5〜4等身）**: `hero-oscar.png` と同じ丸顔・デフォルメ体型か？（5〜6頭身のリアル化は即却下）
- [ ] **2. 画風・タッチ**: 手描き水彩・絵本・コミックエッセイ調の柔らかいブラウン線か？
- [ ] **3. キャラクター設定**: 茶髪マッシュ、真ん丸細縁メガネ、くすみ水色スウェットが維持されているか？
- [ ] **4. 構図の独自性（挿入画）**: サムネイルと同一構図になっていないか？本文の別エピソードを描いているか？
- [ ] **5. 常識的考証**: シャンプー台のガーゼ、カフェのコーヒー手渡し、コンビニの袋分けなど、現実の習慣と合致しているか？
- [ ] **6. 身体の整合性**: 腕は左右2本のみ、指は5本で奇形がないか？
- [ ] **7. 日本語テキスト**: 吹き出しや看板の日本語に崩れ・誤字がないか？
