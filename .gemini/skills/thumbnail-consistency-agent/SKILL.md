# 🎨 サムネイル一貫性 ＆ 主人公登場検証エージェント (Thumbnail Consistency Guardian)

本スキルは、**「オスカーの日本語学習帳」**（https://nihongo.oscarchair.jp/）において、新記事のサムネイル画像生成・記事投稿時に、**各連載カテゴリーのデザイン形式の維持**と**主人公（オスカー）の登場・ビジュアル一貫性**を100%保証するための専門エージェントガイドラインです。

---

## 1. 🪝 発動トリガー ＆ ライフサイクルフック (Lifecycle Hooks)

本エージェントは以下の契機で自動または手動で発動します：
- **`pre_post_publish`**: 新規記事をWordPressに投稿・公開する直前（必須チェックゲート）
- **`post_file_save`**: `content/posts/*.md`（記事Markdown）が保存・新規作成されたとき
- **`post_image_generation`**: `generate_image` でサムネイルが生成された直後
- **手動指示**: 「サムネイルをレビューして」「主人公が出ているか確認」「画像形式チェック」等のユーザー指示時

## 3. 📐 カテゴリー別デザイン形式（系統分類ルール）

各カテゴリーのテーマに合わせ、以下の構図・カラー・必須要素を厳密に遵守して画像を生成・検証します。

```
連載カテゴリー別サムネイル規格
├── 🔍 くらべてみました (kurabete)
│   ├── 構図: 左右分割のVS対比構図（2つの概念・言葉・文化の比較）
│   ├── 主人公: 中央または片側で両方の違いを真剣＆ユーモラスに考察・比較するポーズ
│   └── 配色: 左右で対照的なパステル2色（例: オレンジ×ブルー、イエロー×ブルー）
├── 🗣️ ことばのあや (kotoba-no-aya)
│   ├── 構図: 会話・コミュニケーション・気づきを象徴する構図
│   ├── 主人公: 笑顔や納得の表情で解説・コミュニケーションを行うポーズ
│   ├── 要素: 吹き出し、電球（ひらめき）、ハート・音符などの感情アイコン
│   └── 配色: 優しいパステルラベンダー（#F0E7F5）、ミントグリーン、ソフトピンク
└── 🌏 カルチャーショック (culture-shock)
    ├── 構図: 日本と海外（香港/中華圏/欧米）の日常・習慣・食文化のギャップ
    ├── 主人公: 驚きや発見のリアクション（指差し、キョロキョロ、目を丸くする等）
    │           ※毎回同じ固定ポーズではなく、状況に応じた多様なリアクション
    ├── 要素: 対比となる具体的なアイテム（例: 氷水vs温かい急須、電車で寝る人々、おにぎりvsチャーハン）
    └── 配色: パステルオレンジ、スカイブルー、ライトイエローの明るいコントラスト
```

## 4. 🖼️ サムネイル共通フォーマット規格

- **アスペクト比**: **16:9**（横長、1920×1080 / 1280×720 相当）
- **タイポグラフィ**: 太字でポップな日本語見出しテキスト（縁取り・ドロップシャドウ付き）を画面内に明瞭に配置
- **アートスタイル**: クリーンで親しみやすいアニメ・ベクターイラスト調、滑らかなパステルグラデーション
- **保存形式**: JPG（WebP変換対応）、ファイル名は `thumb-post-{id}.jpg` または `thumb-{category}-{slug}.jpg`

## 5. ✅ 投稿前品質検証チェックリスト (Quality Gate)

記事をWordPressに投稿・公開する前に、以下の5項目をすべてパスしていることを検証します：

- [ ] **1. 主人公・モデル原型の確認**: 公式モデル原型（`hero-oscar-v2.png`）と照合し、オスカー（茶髪ふんわりマッシュ・丸メガネ・水色スウェット）が正確に描かれているか？
- [ ] **2. 腕・手チェック**: 腕が左右2本のみであり、指や体の奇形・不自然さがないか？
- [ ] **3. 表情・ポーズの多様性**: 記事のシチュエーションに応じた自然なリアクション・驚き・ポーズになっているか（画一化の防止）？
- [ ] **4. カテゴリー形式の合致**:
  - `くらべてみました`: 左右VS対比構図になっているか？
  - `ことばのあや`: 会話吹き出し・ひらめき要素と優しいパステル配色か？
  - `カルチャーショック`: 状況に応じた自然な驚き・発見リアクションと文化比較アイテムが描かれているか？
- [ ] **5. UIバッジ干渉回避**: サムネイル左上（約110×30px）のカテゴリーバッジ領域に重要な文字やキャラクターの顔が被っていないか？
- [ ] **6. タイトル文字の可読性**: サムネイル内の日本語テキストに誤字がなく、読みやすいか？
- [ ] **7. アスペクト比と解像度**: 16:9比率で、WordPressアイキャッチとして鮮明に表示されるか？
