異国の地で一人暮らしをしていて、最も心細く不安になる瞬間。それは間違いなく**「急な病気や体調不良で病院（クリニック）に行くとき」**です。

熱で頭がガンガンし、喉が痛くて声も出ない中、なんとか近所の「内科クリニック」のドアを開けたクルマ。しかし、そこには過酷な言語の試練が待ち受けていました。

> 🏥 **受付のスタッフ**：「初診（しょしん）ですね。健康保険証（またはマイナンバーカード）をお預かりします。……では、こちらの**『問診票（もんしんひょう）』**にご記入の上、体温計でお熱を測ってお待ちくださいね！」  
> 🚗 **クルマ**：「（は、はい……って、渡された紙を見て息が止まる！）……**『悪寒（おかん）』『倦怠感（けんたいかん）』『既往症（きおうしょう）』『服用中のお薬』『アレルギー歴』**……！？ な、なにこの激ムズ漢字！？ JLPTのN1でも見たことない単語ばかりだよ……！ 熱で頭が回らないのに、どこに丸をつければいいのか全然わからないーーーっ！！」

普段の日常会話や買い物の日本語には慣れていても、**「医療機関で使われる日本語」**は独特の漢語や医学用語が多く、日本人でも一瞬戸惑うことがあります。

さらに、診察が終わって「お大事に〜」と送り出された後、病院の中では薬をもらえず、**「処方箋（しょほうせん）を持って外の薬局へ行ってください」**と言われて二度びっくり！

今回は、体調を崩した時にパニックにならず、スムーズにお医者さんに症状を伝えて正しい薬を手に入れるための**「日本のクリニック＆調剤薬局サバイバル完全マニュアル」**をお届けします！

## 🎯 今回の語彙（重要ボキャブラリー）

この学習ノートに登場した、覚えておきたい重要日本語：

* **初診（しょしん）** 【JLPT N2】
  * 意味：first medical examination / first visit
  * 例文：その病院を初めて受診するときは「初診料」がかかります。
* **問診票（もんしんひょう）** 【JLPT N2】
  * 意味：medical questionnaire
  * 例文：受付で渡された問診票に、現在の症状や過去の病歴を記入する。
* **処方箋（しょほうせん）** 【JLPT N2】
  * 意味：prescription
  * 例文：医師から発行された処方箋を調剤薬局に提出して、薬を受け取る。
* **副作用（ふくさよう）** 【JLPT N2】
  * 意味：side effect
  * 例文：眠気の副作用が出やすい薬なので、運転前の服用は控えてください。
* **頓服（とんぷく）** 【JLPT N1】
  * 意味：medicine taken only when needed (e.g. painkiller, fever reducer)
  * 例文：解熱剤は毎食後ではなく、熱が38.5℃以上出たときの頓服薬として処方された。
* **ジェネリック医薬品（じぇねりっくいひん）** 【JLPT N2】
  * 意味：generic drugs (後発医薬品)
  * 例文：先発品と同じ有効成分のジェネリック医薬品を選ぶことで、お薬代を節約できます。

## 1. 病院に行く前に知っておくべき「受診の3大持ち物」

家を出る前に、必ず以下の3点をお財布やバッグに入れたか確認してください。これがないと自費診療（10割全額負担）になってしまい、高額な医療費を支払うことになります！

1. **健康保険証（または保険証登録済みのマイナンバーカード）** ［必須 (SS)］  
   日本に住む人は国民健康保険または会社の社会保険に加入しており、窓口で提示すれば**自己負担は原則「3割」**で済みます。忘れると一時的に全額（10割＝数万円）を立て替える必要があります。
2. **現金（1万円程度）** ［必須 (S)］  
   街の小さな個人クリニックでは、クレジットカードや電子マネー、QRコード決済が使えず**「現金のみ」**の医療機関がまだまだ多く残っています。診察代と薬代を合わせて数千円〜1万円の現金を持参するのが鉄則です。
3. **お薬手帳（持っている場合）** ［推奨 (A)］  
   現在飲んでいる薬がある場合、飲み合わせの事故（相互作用）を防ぐために医師や薬剤師に見せます。紙の手帳だけでなく、スマートフォンの「お薬手帳アプリ」でも代用可能です。

## 2. 問診票の激ムズ漢字を完全攻略！チェック項目対訳表

受付で渡される問診票（アンケート用紙）で最も頻出する難読漢字と、その意味をまとめました。

| 問診票の漢字 | 読み方 | 意味・症状 | 具体的な体のサイン |
| :--- | :--- | :--- | :--- |
| **発熱** | はつねつ | fever | 熱がある（体温計で37.5℃以上） |
| **悪寒** | **おかん** | chills | ブルブルと寒気がする、ゾクゾクする |
| **倦怠感** | **けんたいかん** | fatigue, sluggishness | 体がだるい、鉛のように重くて動けない |
| **嘔吐 / 吐き気** | おうと / はきけ | vomiting / nausea | 吐いてしまった、胃がムカムカして気持ち悪い |
| **下痢** | **げり** | diarrhea | お腹を壊して便が水っぽい |
| **既往歴 / 既往症**| **きおうれき** | past medical history | 過去にかかった大きな病気や手術 |
| **アレルギー** | あれるぎー | allergies | 薬や食べ物（卵、甲殻類、花粉など）への過敏反応 |
| **妊娠中 / 授乳中**| にんしんちゅう | pregnant / nursing | 胎児や母乳に影響する薬を避けるための必須確認 |

問診票に「いつから（何日前から）」「どんな症状か」を丸で囲む欄があります。漢字が読めなくても、上記の表の単語を見つけて丸をつければOKです！

## 3. 診察室でお医者さんに100%伝わる「オノマトペ」症状表現

診察室に呼ばれたら、お医者さんから「今日はどうされましたか？」と尋ねられます。
日本語には痛みの種類を表現する豊かな**「オノマトペ（擬音語・擬態語）」**があり、これを使うとお医者さんは一瞬で症状のレベルを正確に把握してくれます！

```
【痛みの種類を表す魔法のオノマトペ】
● 頭が【 ズキズキ 】痛む ━━ 血管が脈打つように「ズキン、ズキン」と痛む（偏頭痛）
● 喉が【 イガイガ 】する ━━ 喉にトゲが刺さったように引っかかる、乾燥して荒れている
● お腹が【 キリキリ 】痛む ━━ 針やナイフで刺されるように鋭く痛む（胃痛、ストレス）
● 関節が【 ギシギシ / ミシミシ 】する ━━ 高熱の出始めに手足のフシブシが痛む
● お腹が【 ゴロゴロ 】鳴る ━━ お腹が下りそう、ガスや水分が溜まっている
● 咳が【 コンコン 】出る ━━ 乾いた軽い咳（初期の風邪）
● 咳が【 ゴホゴホ 】出る ━━ 痰（たん）が絡んだ重い咳（気管支炎など）
● 頭が【 クラクラ 】する ━━ めまいがして立ちくらみがする
```

### お医者さんに伝える黄金フレーズ：
* **「一昨日（おととい）の夜から、熱が38度5分まで上がりました。」**（いつから・どのくらい）
* **「喉が痛くて、唾（つば）を飲み込むのが辛いです。」**（具体的な支障）
* **「咳が止まらなくて、夜眠れません。」**（生活への影響）
* **「市販の風邪薬を飲みましたが、あまり効きませんでした。」**（薬の服薬状況）

## 4. 病院の外へ！？「院外処方」と調剤薬局のシステム

お会計を済ませると、領収書と一緒に**「A4サイズの処方箋（しょほうせん）」**というピンクや水色の紙を渡されます。
「え？ 薬はどこで受け取るの？」と院内を探しても薬局はありません。

```
【日本の医薬分業システム（院外処方）】
［クリニックで診察・お会計］
       │
       ▼ （処方箋の紙を受け取る）
［病院の外に出る］
       │
       ▼ （すぐ隣や向かいにある「〇〇調剤薬局」の看板を探す）
［調剤薬局の受付に処方箋と保険証を提出］
       │
       ▼ （薬剤師が薬を調合・ダブルチェック）
［薬剤師から薬の飲み方の説明を受けて、薬代をお支払い！］
```

### ⚠️ 【超重要】処方箋には「4日間の有効期限」がある！
処方箋の有効期限は、**発行された日を含めて「4日以内」**です！ 日曜日や祝日もこの4日間にカウントされます。
「今日はしんどいから、薬は週末に薬局へもらいに行こう……」と放置して5日目に薬局に行くと、処方箋が無効になり、薬をもらえなくなります（もう一度病院で初診料を払って再発行してもらう羽目になります）。病院を出たら、その足で真っ直ぐ隣の調剤薬局へ行きましょう！

## 5. 調剤薬局でのカウンター会話とお薬の飲み方ルール

調剤薬局に入ると、薬剤師さんからいくつか重要な質問をされます。慌てずに答えられるように準備しておきましょう。

### ① 「ジェネリック医薬品（後発品）をご希望されますか？」
* **背景**：新薬（先発品）の特許が切れた後に作られる、同じ有効成分・同じ効能の薬です。
* **回答のコツ**：特にこだわりがなければ、**「はい、ジェネリックでお願いします」**と答えましょう。薬代が30%〜50%ほど安くなります！

### ② お薬袋（薬包紙）に書かれた服薬タイミングの専門用語

薬局で受け取る薬の袋には、飲むタイミングが記されています。日本語独特の言い回しに注意しましょう。

| 服薬指示 | 意味 | タイミング | 注意点 |
| :--- | :--- | :--- | :--- |
| **食後（しょくご）** | after meals | ご飯を食べ終わってから**30分以内** | 胃を荒らさないための最も一般的な指定 |
| **食前（しょくぜん）** | before meals | ご飯を食べる**30分〜1時間前** | 胃が空っぽの時に吸収させたい漢方薬や吐き気止め |
| **食間（しょっかん）** | between meals | 食事と食事の間（**食後2時間後**） | **「食事中」という意味ではありません！** 胃が空の時 |
| **就寝前（しゅうしんまえ）** | before bedtime | 寝る**30分〜1時間前** | 睡眠薬や翌朝効かせたい便秘薬など |
| **頓服（とんぷく）** | as needed | 症状が出た時だけ飲む | 痛み止めや解熱剤。「1日2回まで、4時間以上あける」等 |

## 6. まとめ：体調不良の街角サバイバル心得

1. **家を出る前に「保険証（マイナカード）」と「現金1万円」を必ず確認！**
2. **問診票の「悪寒（寒気）」「倦怠感（だるさ）」に丸をつける！**
3. **お医者さんには「ズキズキ（頭）」「イガイガ（喉）」のオノマトペで伝える！**
4. **もらった処方箋は「4日以内」にすぐ近くの調剤薬局へ持参する！**
5. **薬代を節約したいなら「ジェネリック希望」と伝える！**
6. **「食間」は食事中ではなく「食後2時間後」のこと！**
