しかし、留守にしていて荷物を受け取れなかった時に現れるこの**「不在票ダンジョン」**は、漢字だらけの用紙と自動音声のタイムアタックにより、多くの外国人をパニックに陥れる難所なのです！

## 🎯 今回の語彙（重要ボキャブラリー）

この学習ノートに登場した、覚えておきたい重要日本語：

* **不在票（ふざいひょう）** 【JLPT N2】
  * 意味：delivery notice, missed delivery slip
  * 例文：留守中に荷物が届いたため、ポストにご不在連絡票が入っていた。
* **再配達（さいはいたつ）** 【JLPT N2】
  * 意味：redelivery
  * 例文：不在票に記載されているQRコードを読み取って、本日の夜に再配達を依頼した。
* **伝票番号（でんぴょうばんごう）** 【JLPT N2】
  * 意味：tracking number, slip number
  * 例文：再配達の申し込みには、用紙に印字された12桁のお問い合わせ伝票番号が必要です。
* **置き配（おきはい）** 【JLPT N3】
  * 意味：unattended delivery (leaving package at the front door)
  * 例文：日中留守にすることが多いので、玄関前への置き配を指定した。

## 1. 不在票の解読術：どこに何が書いてあるのか？

ポストに入っていた紙（ヤマト運輸の緑・黄色、佐川急便の青、日本郵便の赤）には、たくさんの情報が詰め込まれています。
焦る必要はありません！ **見るべき場所はたったの「3ヶ所」だけ**です！

```
【不在票の重要チェックポイント3選】
┌──────────────────────────────────────────────┐
│ [運送会社ロゴ]  ご不在連絡票                  │
├──────────────────────────────────────────────┤
│ ①【お届け日時】：10月7日 14時35分            │ ＝ いつ配達に来たか
│ ②【お荷物の種類】：クール便・代金引換など    │ ＝ 特別な受け取りが必要か
├──────────────────────────────────────────────┤
│ ③ ★【お問い合わせ伝票番号】                   │ ＝ ★超重要！
│     1 2 3 4 - 5 6 7 8 - 9 0 1 2              │   再配達受付に必要な12桁のID
├──────────────────────────────────────────────┤
│ ④【再配達受付のQRコード】                    │ ＝ スマホでここをスキャン！
│ ⑤【担当ドライバーの直通電話番号】           │ ＝ 当日すぐ持ってきてほしい時
└──────────────────────────────────────────────┘
```

### チェック①：お問い合わせ伝票番号（11〜12桁）
用紙の中央あたりにバーコードと一緒に印字されている数字です。WEBでも電話でも、この番号を入力することであなたの荷物が特定されます。

### チェック②：保管期限（ほかんきげん）
通常、**不在票が入った日から「7日間」**が保管期限です。7日を過ぎると、荷物は送り主（Amazonの倉庫や実家）へ勝手に送り返されてしまいます！ 必ず3日以内に手続きをしましょう。

### チェック③：荷物の種類（普通便か、冷蔵・冷凍か、代引か）
* **クール便（冷蔵・冷凍）**：宅配ボックスに入れられないため、対面での受け取りが必須です。
* **代金引換（コレクト）**：玄関で現金や電子マネーを支払う必要があります。

## 2. 最も簡単！WEB・スマホ・LINEを使った「3分再配達受付」

自動音声の電話（0570〜など）にかけると通話料がかかり、番号のプッシュ入力で焦ってしまいます。
現代の日本で最もおすすめなのは、**「スマホのカメラでQRコードを読み取る方法」**です！

```
【スマホ再配達の最短ステップ】
1. スマホのカメラで不在票の「QRコード」をパシャリと読み取る。
       │
       ▼
2. 伝票番号が自動入力された専用受付ページが開く！
       │
       ▼
3. 【希望日】を選ぶ（今日／明日／明後日など）
       │
       ▼
4. 【希望時間帯】を選ぶ（午前中／14-16時／16-18時／18-20時／19-21時）
       │
       ▼
5. 申し込み完了！ 指定した時間に家で待つだけ！
```

### 当日再配達の「締め切りタイムリミット」に注意！
「今すぐ持ってきてほしい！」と思っても、当日中に再配達してもらえる時間には限界があります。
* **WEB受付の場合**：当日の**17:00〜18:00頃**まで
* **ドライバー直通電話の場合**：当日の**19:00頃**まで
夕方19時を過ぎてから不在票に気づいた場合は、素直に「明日の午前中」や「明日の夜」を指定しましょう。

## 3. 主要宅配キャリア別：再配達申し込み方法比較

日本の3大宅配キャリアの再配達方法と特徴を比較しました。

| キャリア（会社名） | テーマカラー | 最も便利な再配達方法 | LINE連携・特徴 |
| :--- | :---: | :--- | :--- |
| **ヤマト運輸（クロネコヤマト）** | **黄色・緑** | 公式LINEアカウント / クロネコメンバーズ | LINEで友達追加すると、不在通知がメッセージで届き、チャットで再配達指定可能。 |
| **佐川急便（SAGAWA）** | **青・白** | 不在票のQRコードからWEB受付 | 佐川急便公式LINEやスマートクラブで日時変更可能。 |
| **日本郵便（ゆうパック）** | **赤・白** | 郵便局公式LINE「ぽすくま」 / WEB | LINEの「ぽすくま」に不在票の写真を送るだけで、AIが自動認識して再配達手配完了！ |

特に日本郵便の公式LINEキャラクター**「ぽすくま」**は、不在票をスマホで撮影してLINEに送信するだけで、AIが伝票番号を自動で読み取ってくれる神機能があります！ 外国人学習者にも大絶賛されています。

## 4. もう不在票で悩まない！「置き配（おきはい）」とコンビニ受け取り

日中仕事や学校で忙しく、夜も何時に帰れるかわからない人は、そもそも最初から不在票を出さないテクニックを活用しましょう！

### ① 玄関前への「置き配（おきはい）」指定
* Amazonなどの通販サイトでは、注文時に配送オプションで**「置き配指定：玄関前」**を選ぶことができます。
* 配達員さんがチャイムを鳴らさずにドアの横に荷物を置いて、配達完了写真をメールで送ってくれます。
* 日本は治安が良いため盗難のリスクは非常に低いですが、雨に濡れない場所か確認しておきましょう。

### ② コンビニ受け取りサービス
* 自宅近くのファミリーマート、セブンイレブン、ローソンを届け先に指定できます。
* 24時間いつでも自分の都合の良い時に、レジでバーコードを見せるだけで荷物が受け取れます。
